## 1. 系统概述

SOP 防呆系统是一套基于 AI 视觉识别的产线作业防错系统，核心功能包括：

- **SOP 步骤识别**：通过摄像头实时监测操作员是否按 SOP 步骤操作
- **物料防错**：自动识别当前使用的物料是否与 BOM 匹配
- **完工检查**：对比完工状态与标准照片，检测遗漏或异常
- **实时报警**：发现异常立即触发声光报警并推送飞书通知
- **数据追溯**：所有操作全程记录，支持视频回放和数据导出

### 系统角色

| 角色 | 权限范围 |
|------|----------|
| **管理员 (admin)** | 所有功能 + 用户管理 + 系统配置 + 数据管理 |
| **操作员 (operator)** | 仪表盘、工单查看、报警查看、视频回放 |

## 2. 登录与权限

### 登录步骤

1. 打开浏览器，访问系统地址（默认：`http://服务器IP:8080`）
2. 输入用户名和密码
3. 点击「登 录」按钮

### 注意事项

- 登录错误 5 次后将临时锁定 IP，需等待后重试
- 登录会话有效期为 24 小时，过期后需重新登录
- 首次使用请联系管理员分配账号

## 3. 仪表盘

登录后默认进入仪表盘页面，展示系统运行概览：

- **今日工单统计**：总数、进行中、已完成、失败
- **报警统计**：按严重级别分类（严重/警告/信息）
- **未确认报警数**：实时更新，红色角标提示

### 操作

- 点击统计卡片可快速跳转到对应模块
- 仪表盘数据每次进入页面时自动刷新

## 4. 工位管理

管理产线上的工位信息。

### 查看工位列表

左侧菜单点击「工位监控」，可看到所有工位的当前状态。

### 添加工位（管理员）

1. 进入工位管理页面
2. 点击「新建工位」
3. 填写工位名称、编码、边缘设备 ID 等信息
4. 点击「确定」保存

### 工位字段说明

| 字段 | 说明 |
|------|------|
| 工位名称 | 工位的显示名称，如"SMT-1" |
| 工位编码 | 工位唯一标识，用于边缘端通信 |
| 边缘设备 ID | 与边缘计算设备关联的 ID |
| 描述 | 工位的补充说明 |

## 5. SOP 模板管理

SOP 模板定义了产品的标准操作步骤。

### 查看模板

左侧菜单点击「SOP 配置」查看所有 SOP 模板。

### 创建模板（管理员）

1. 点击「新建模板」
2. 填写模板名称和版本号
3. 添加步骤：每个步骤包含名称和描述
4. 设置模板状态（启用/停用）
5. 点击「保存」

### 模板状态

- **启用**：可被工单关联使用
- **停用**：不会出现在工单创建的模板选择中

## 6. 工单管理

工单是系统的核心业务单元，记录一次完整的产品组装过程。

### 查看工单列表

左侧菜单点击「工单管理」。

### 筛选工单

- **按序列号**：输入产品 SN 号搜索
- **按状态**：筛选进行中/已完成/失败的工单
- **按日期范围**：选择时间区间

### 创建工单

1. 点击「新建工单」
2. 输入产品序列号（SN）
3. 选择工位
4. 选择 SOP 模板
5. 点击「确定」

### 查看工单详情

点击工单列表中的某一行，弹出详情窗口，显示：
- 工单基本信息
- 每个步骤的执行结果（通过/失败/跳过）
- 步骤的置信度和快照图片

### 导出工单数据

点击「导出 Excel」按钮，系统将生成包含所有工单数据的 Excel 文件下载。

## 7. 报警管理

### 查看报警

左侧菜单点击「报警管理」查看所有报警记录。

### 报警级别

| 级别 | 含义 | 颜色 |
|------|------|------|
| 严重 (CRITICAL) | 需要立即处理的异常 | 红色 |
| 警告 (WARN) | 需要关注的异常 | 黄色 |
| 信息 (INFO) | 一般性通知 | 蓝色 |

### 确认报警

1. **单条确认**：点击报警行末尾的「确认」按钮
2. **批量确认**：勾选多条报警，点击「批量确认」

### 导出报警数据

点击「导出 Excel」按钮导出报警记录。

### 飞书通知

系统可将报警自动推送到飞书群：
- 管理员在「通知配置」页面配置飞书机器人 Webhook URL
- 可设置最低推送级别（仅严重/警告及以上/全部）
- 推送消息为卡片格式，包含告警类型、工位、严重级别等信息

## 8. 物料校验

记录 AI 对物料的识别和校验结果。

### 查看记录

左侧菜单点击「物料校验」。

### 字段说明

| 字段 | 说明 |
|------|------|
| BOM 物料项 | 标准 BOM 中应使用的物料标识 |
| 识别物料 | AI 实际识别到的物料 |

## 9. 完工检查

完工检查通过对比完工照片与标准参考照片来判断组装是否完成。

### 查看记录

左侧菜单点击「完工确认」。

### 字段说明

| 字段 | 说明 |
|------|------|
| 相似度 | 完工照片与参考照片的相似程度 |
| 检查项 | 检查的具体项目列表 |
| 缺陷说明 | 如果不通过，记录具体的缺陷描述 |

## 12. 系统管理（管理员）

以下功能仅管理员可见和操作。

### 12.1 用户管理

**路径**：左侧菜单 → 用户管理

| 操作 | 说明 |
|------|------|
| 添加用户 | 设置用户名、密码、角色（admin/operator） |
| 修改密码 | 重置用户密码 |
| 删除用户 | 移除用户（不可删除自己） |

### 12.2 放行审计

**路径**：左侧菜单 → 放行审计

记录所有强制放行（跳过防呆检查）的操作，包含：
- 被放行的工单和步骤
- 操作员工号
- 放行原因
- 操作时间和视频证据

### 12.3 通知配置

**路径**：左侧菜单 → 通知配置

配置飞书机器人告警推送：

1. 在飞书群中添加自定义机器人，获取 Webhook URL
2. 粘贴到「Webhook URL」输入框
3. 选择最低推送级别
4. 点击「保存配置」
5. 点击「发送测试消息」验证配置是否正确

### 12.4 审计日志

**路径**：左侧菜单 → 审计日志

记录系统中所有写操作（创建/更新/删除），支持：
- 按操作类型筛选
- 按资源类型筛选
- 按用户筛选
- 查看操作详情和来源 IP

### 12.5 数据管理

**路径**：左侧菜单 → 数据管理

管理系统数据的生命周期：
- 清理历史数据
- 查看数据量统计

### 12.6 数据导出

在工单管理和报警管理页面，管理员可以：
- 点击「导出 Excel」下载数据
- 导出文件包含中文表头和格式化数据
- 支持按筛选条件导出

## 13. 常见问题

### Q: 忘记密码怎么办？

联系管理员在「用户管理」页面重置密码。

### Q: 报警响了但不是真正的异常？

1. 确认报警以消除提示
2. 如果频繁误报，联系管理员调整 AI 模型的置信度阈值
3. 必要时可在系统中使用「强制放行」功能，但会记录到审计日志

### Q: 工单创建后发现 SOP 模板选错了？

当前不支持修改已创建工单的 SOP 模板。建议：
1. 如果工单尚未开始，可以删除后重新创建
2. 如果工单已开始，联系管理员处理

### Q: 导出的 Excel 文件打不开？

- 确保使用 Microsoft Excel 或 WPS Office 打开
- 如果文件名显示乱码，将文件名改为英文后缀 `.xlsx` 再尝试

### Q: 飞书收不到告警通知？

1. 检查「通知配置」中 Webhook URL 是否正确
2. 确认「启用通知」开关已打开
3. 点击「发送测试消息」验证
4. 检查飞书群中的机器人是否还在有效状态

### Q: 系统访问速度慢？

1. 检查网络连接
2. 大量数据时使用筛选条件缩小查询范围
3. 联系管理员检查服务器资源使用情况
